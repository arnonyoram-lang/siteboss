# SiteBoss — ניהול אתר הבנייה

אפליקציה לטלפון בשביל מנהלי עבודה בענף הבנייה. עברית וערבית.
הכול במקום אחד: יומן עבודה, ליקויים, בטיחות יומית, נוכחות, קליטת עובדים, כלים וציוד, היתרי עבודה, אירועי בטיחות, הודעות מהמשרד ועוזר חכם.

## איפה זה
- האפליקציה למנהלים: https://arnonyoram-lang.github.io/siteboss/
- עמוד הניהול (רק לבעלים): https://arnonyoram-lang.github.io/siteboss/admin.html
- הקוד: מאגר `arnonyoram-lang/siteboss`. כל שמירה לענף `master` עולה לאתר לבד תוך דקה–שתיים.

## הקבצים העיקריים
- `siteboss.html` — כל האפליקציה בקובץ אחד. `index.html` הוא עותק זהה שלו (חובה להעתיק אחרי כל שינוי).
- `admin.html` — עמוד הניהול.
- `firestore.rules`, `storage.rules` — כללי ההרשאות של הענן (Firebase).
- `CLAUDE.md` — פירוט טכני מלא להמשך עבודה.

## איך מריצים במחשב
מתוך התיקייה: `npx serve -p 3456 .` ואז לפתוח http://localhost:3456

## איפה נשמרים הנתונים
- בטלפון של המנהל. עותק נשלח לענן (Firebase) כדי שהמשרד יראה.
- צילומי המסמכים והחתימות של עובדים וכלים נשמרים באזור האחסון הגדול של הטלפון, כך שאפשר לקלוט מאות עובדים בלי שהזיכרון יתמלא.

- להעלות לענן גם את צילומי המסמכים של העובדים (כיום רק השם, הפרטים והחתימה עולים).
